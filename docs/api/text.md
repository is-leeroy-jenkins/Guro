# Text Module API

`instructions.text` exposes **172** instruction constants plus the discovery helpers below.

::: instructions.text
    options:
      members:
        - names
        - values
        - items
        - get
      show_source: false
      heading_level: 2

## Prompt Constants

The constant values are intentionally not expanded by mkdocstrings because many prompts are long Markdown documents. Use the [Prompt Catalog](../reference/catalog.md) to browse names and categories, then access the selected value directly from Python.
